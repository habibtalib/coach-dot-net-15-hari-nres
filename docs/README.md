## Cara guna

- **Peserta:** baca contoh PRD ini selepas slaid *"Anatomi PRD ringkas"* dan *"PRD: kabur vs jelas"*, kemudian tulis PRD anda sendiri untuk modul kumpulan anda mengikut anatomi 7 bahagian yang sama.
- **PRD anda** mesti berpaksi pada URS modul anda (`_sumber-urs/`) + kanun teknikal (`AGENTS.md` repo anda + `SPEC-KURSUS.md`). Jangan reka keperluan; tandakan yang belum pasti sebagai **soalan terbuka**.
- Setiap **user story** + acceptance criteria menjadi kad Jira; **AC = Definition of Done**.

> Semua contoh **sintetik**. Jangan simpan data NRES sebenar.
