# Prompt umum — Hari 5–6 (Borang & peraturan perniagaan)

> **Guna pada permulaan hari.** Prompt **am** (bukan modul-spesifik) untuk mengorientasi pembantu AI anda ke konteks kursus + matlamat hari ini. Ganti `<...>`. Prompt bernombor mengikut tugas: [`../docs/pustaka-prompt.md`](../docs/pustaka-prompt.md).

```text
Rujuk AGENTS.md dan SPEC-KURSUS.md. Saya bekerja dalam repo/modul <sistem>.
Matlamat Hari 5–6: borang lengkap + peraturan perniagaan modul (validation di pelayan).
Sebelum menjana kod: sahkan repo/modul saya, cari komponen sedia ada (jangan pendua),
borang mengikat ViewModel (bukan entiti), kuatkuasa peraturan di pelayan, dan ikut aliran
setiap tugas — Jira (In Progress) → cabang feat/<ciri> → SMK-01 → PR (Closes KEY-n).
Jangan reka keperluan; yang tak pasti, tanya. Tunjuk diff dahulu.
```

- **Selepas:** ikut prompt bernombor — `DEV-01`→`DEV-04` (ViewModel → View → controller draf → validation pelayan). Kandungan trek: `kumpulan-N-…/hari-5-6/`.
