# Prompt umum — Hari 15 (Integrasi, SIT/UAT & demo)

> **Guna pada permulaan hari.** Prompt **am** (bukan modul-spesifik) untuk mengorientasi pembantu AI anda ke konteks kursus + matlamat hari ini. Ganti `<...>`. Prompt bernombor mengikut tugas: [`../docs/pustaka-prompt.md`](../docs/pustaka-prompt.md). QA/UAT dipandu-AI: [`../docs/lab-qa-ai-uat.md`](../docs/lab-qa-ai-uat.md).

```text
Rujuk AGENTS.md dan SPEC-KURSUS.md. Hari ini sesi bersama: integrasi + SIT/UAT pre-check + demo.
Matlamat: sahkan aliran rentas modul (staf baharu: Lapor Diri → profil → guna sistem via SSO),
Papan Pemuka Induk, kesempurnaan audit, dan RBAC (setiap semakan salah peranan mesti 403).
Rekod lulus/gagal. INGAT: ini pre-check — UAT sebenar dijalankan pengguna NRES.
Jangan deploy ke production dari sesi ini. Tunjuk diff dahulu.
```

- **Selepas:** ikut prompt bernombor — `UJI-02`/`UJI-03` (SIT/UAT pre-check pelayar), `SMK-01`. Kandungan: `hari-15/` (Latihan 6b = pre-check dipandu-AI).
