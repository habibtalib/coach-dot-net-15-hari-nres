# Prompt umum — Hari 2 (Git, Agile & kolaborasi)

> **Guna pada permulaan hari.** Prompt **am** (bukan modul-spesifik) untuk mengorientasi pembantu AI anda ke konteks kursus + matlamat hari ini. Ganti `<...>`. Prompt bernombor mengikut tugas: [`../docs/pustaka-prompt.md`](../docs/pustaka-prompt.md).

```text
Rujuk AGENTS.md dan SPEC-KURSUS.md. Saya dalam kumpulan <N>, modul <sistem>.
Matlamat Hari 2: backlog Agile + aliran Git/PR + kolaborasi. Dari user story PRD Hari 1,
sediakan isu Jira (tajuk + acceptance criteria = Definition of Done) dan sahkan aliran
setiap tugas — Jira → cabang feat/<ciri> → commit (KEY-n) → PR (Closes KEY-n) → Done.
Jangan reka keperluan. Tunjuk draf dahulu sebelum mencipta isu.
```

- **Selepas:** ikut prompt bernombor — `JIRA-01`/`JIRA-02` (Jira), `SMK-01` (semakan pra-PR), `MEM-01` (memory). Kandungan: `hari-2/`.
