# Prompt umum — Hari 1 (Perancangan, URS & ERD)

> **Guna pada permulaan hari.** Prompt **am** (bukan modul-spesifik) untuk mengorientasi pembantu AI anda ke konteks kursus + matlamat hari ini. Ganti `<...>`. Prompt bernombor mengikut tugas: [`../docs/pustaka-prompt.md`](../docs/pustaka-prompt.md).

```text
Rujuk AGENTS.md dan SPEC-KURSUS.md. Saya dalam kumpulan <N>, modul <sistem>.
Matlamat Hari 1: fahami keperluan (URS), draf PRD, dan ERD modul — dari URS/dokumen NRES.
Jangan reka keperluan atau entiti; yang tak pasti, senaraikan sebagai soalan terbuka.
Guna Bahasa Melayu untuk nota, English untuk nama entiti. Berpaksi URS + SPEC-KURSUS.
```

- **Selepas:** ikut prompt bernombor — `PRD-01`/`PRD-02` (PRD), `DIA-01`…`DIA-08` (diagram), `UI-01` (mockup). Kandungan: `hari-1/`.
